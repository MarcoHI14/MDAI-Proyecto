Diagrama de Entidad-Relación (ER):

1. Usuario
   - id (PK)
   - username
   - email
   - password

2. Artista
   - id_usuario (PK, FK a Usuario.id)
   - biografia

3. Cancion
   - id (PK)
   - titulo
   - id_artista (FK a Artista.id_usuario)

4. Playlist
   - id (PK)
   - nombre
   - id_usuario (FK a Usuario.id)

5. CancionPlaylist
   - id_playlist (FK a Playlist.id)
   - id_cancion (FK a Cancion.id)

6. SolicitudVerificacion
   - id (PK)
   - id_usuario (FK a Usuario.id)

Relaciones:
- Usuario 1:1 Artista
- Usuario 1:N Playlist
- Usuario 1:1 SolicitudVerificacion
- Artista 1:N Cancion
- Playlist N:M Cancion (a través de CancionPlaylist)
